```bash

xcrun notarytool history --keychain-profile taproot-notary
```

## Step 3 — Build with timestamped signatures

```bash
mkdir -p /tmp/staging-0.1.2
bash helper-mac/scripts/release/build-app.sh /tmp/staging-0.1.2 --zip
```

**Assert — timestamped signatures present:**

```bash
codesign -dvv /tmp/staging-0.1.2/TaprootHelper.app/Contents/MacOS/TaprootHelper 2>&1 | grep -i timestamp
# Expected: line containing "Timestamp=" with a real date/time
```

**Assert — app signs cleanly:**

```bash
codesign --verify --deep --strict --verbose=2 /tmp/staging-0.1.2/TaprootHelper.app
# Expected: no errors
```

---

## Step 4 — Notarize the .app (for Sparkle-delivered updates)

```bash
bash helper-mac/scripts/release/notarize.sh --app /tmp/staging-0.1.2/TaprootHelper.app
```

**Expected output:** `notarytool submit` → `status: Accepted`, then `stapler validate` success.

**Assert — Gatekeeper accepts the notarized .app:**

```bash
spctl -a -vvv -t install /tmp/staging-0.1.2/TaprootHelper.app
# Expected: accepted
#           source=Notarized Developer ID
```

---

## Step 5 — Re-zip stapled .app for Sparkle delivery

```bash
VERSION="0.1.2"
ditto -c -k --keepParent \
  /tmp/staging-0.1.2/TaprootHelper.app \
  /tmp/staging-0.1.2/TaprootHelper-${VERSION}.zip
```

This zip replaces the pre-notarization zip from build-app.sh. The stapled .app inside carries the notarization ticket so Sparkle-delivered installs are Gatekeeper-clean.

---

## Step 6 — Package and notarize the DMG (for first-install download)

```bash
bash helper-mac/scripts/release/package-dmg.sh \
  /tmp/staging-0.1.2/TaprootHelper.app \
  /tmp/staging-0.1.2/

bash helper-mac/scripts/release/notarize.sh \
  --dmg /tmp/staging-0.1.2/TaprootHelper-0.1.2.dmg
```

**Assert — Gatekeeper accepts the notarized DMG:**

```bash
spctl -a -vvv -t open \
  --context context:primary-signature \
  /tmp/staging-0.1.2/TaprootHelper-0.1.2.dmg
# Expected: accepted
#           source=Notarized Developer ID
```

**Assert — both stapler validates succeed:**

```bash
xcrun stapler validate /tmp/staging-0.1.2/TaprootHelper.app
xcrun stapler validate /tmp/staging-0.1.2/TaprootHelper-0.1.2.dmg
# Expected: "The validate action worked!" for both
```

## Step 9 — Rollback / debug

If `notarytool submit` exits non-zero, it prints the submission ID. Inspect with:

```bash
xcrun notarytool log <submission-id> --keychain-profile taproot-notary
```

Most common root causes:

- Missing `--timestamp` on codesign → fixed in T11.10 (build-app.sh line 137)
- Missing hardened runtime → already on in build-app.sh
- Unsigned nested binary → `codesign --verify --deep --strict` will surface it
