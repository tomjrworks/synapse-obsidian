
## Step 8 — Publish DMG to R2

> **⚠️ Cloudflare 404-cache poison:** If anyone (curl, browser, prior smoke) GETs the canonical R2 URL **before** the wrangler upload completes, Cloudflare caches the 404 for up to 4 hours (`max-age=14400`). Upload to R2 **first**, then verify with curl. Never hit the URL pre-upload.

Print the upload command (don't auto-execute — operator reviews first):

```bash
VERSION="0.1.2"
echo "wrangler r2 object put taproot-releases/releases/v${VERSION}/TaprootHelper-${VERSION}.dmg --file=$HOME/Downloads/taproot-releases/${VERSION}/TaprootHelper-${VERSION}.dmg --content-type=application/x-apple-diskimage --remote"
```

Run after reviewing. DMG-only — ZIP is no longer uploaded (appcast switched to DMG in T11.10).

**Assert — object is publicly accessible:**

```bash
curl -I "https://downloads.taproothq.com/releases/v${VERSION}/TaprootHelper-${VERSION}.dmg"
# Expected: HTTP/2 200
```

## Step 10 — Staging Sparkle smoke (DMG auto-update)

First time DMG auto-update path (`SUDiskImageUnarchiver` + `hdiutil` mount/unmount) is exercised in this project. ZIP path was proven in T11.8; DMG path needs its own smoke.

Pre-req: a 0.1.1 (or earlier) build of `TaprootHelper.app` is installed at `/Applications/TaprootHelper.app`.

```bash
# Point the running install at the staging appcast preview URL
defaults write com.taproot.helper SUFeedURL \
  "https://<preview>.taproot-updates.pages.dev/appcast.xml"

# Quit and reopen helper, or trigger a check from the menu
open /Applications/TaprootHelper.app
# Wait ≤60s for Sparkle's automatic check, or use Help → Check for Updates

# Expected: Sparkle update dialog appears → user accepts → DMG downloaded,
# verified (EdDSA), mounted, .app copied, helper relaunches at 0.1.2.

# After confirming success, restore prod feed
defaults delete com.taproot.helper SUFeedURL
```

**Assert — running install is now 0.1.2:**

```bash
defaults read /Applications/TaprootHelper.app/Contents/Info.plist CFBundleShortVersionString
# Expected: 0.1.2
```

## Step 12 — Rollback / debug

If `notarytool submit` exits non-zero, it prints the submission ID. Inspect with:

```bash
xcrun notarytool log <submission-id> --keychain-profile taproot-notary
```

Most common root causes:

- Missing `--timestamp` on codesign → fixed in T11.10 (build-app.sh line 137)
- Missing hardened runtime → already on in build-app.sh
- Unsigned nested binary → `codesign --verify --deep --strict` will surface it
