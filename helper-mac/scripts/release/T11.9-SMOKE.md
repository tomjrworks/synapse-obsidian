## Step 1 — Sign in via web flow

**Pre-state:** TaprootHelper not running. No bearer in Keychain for `taproothq.com`.

**Action:**

1. Launch `TaprootHelper.app` from Applications.
2. Click "Sign in" in the onboarding window (or menubar → Sign In).
3. Complete the OAuth flow in the browser that opens.

**Observed state:**

- Browser redirects via `taproot://` URL scheme back to the helper.
- Onboarding window advances past sign-in step.

**Pass criteria:**

```bash
security find-generic-password -s taproothq.com -w
# Expected: non-empty bearer token string (no "could not be found" error)
```

**Result:** `[ ] PASS  [ ] FAIL — `

## Step 2 — Pick vault folder (first-run)

**Pre-state:** Signed in. No vault folder configured yet.

**Action:** In the first-run window, click "Choose Folder" and select a test vault directory (e.g. `~/Desktop/taproot-smoke-vault/`).

**Observed state:** Helper accepts the folder. First-run window closes or advances.

**Pass criteria:**

```bash
# SettingsStore plist persists the chosen path
defaults read com.taproothq.TaprootHelper localFolder 2>/dev/null || \
  plutil -p ~/Library/Preferences/com.taproothq.TaprootHelper.plist 2>/dev/null | grep -i folder
# Expected: path containing "taproot-smoke-vault"
```

**Result:** `[ ] PASS  [ ] FAIL — `

## Step 3 — Local file propagates to cloud (push path)

**Pre-state:** Sync active. Vault folder set to `~/Desktop/taproot-smoke-vault/`.

**Action:**

```bash
echo "smoke test $(date)" > ~/Desktop/taproot-smoke-vault/smoke-push.md
```

**Observed state:** Within 30 seconds, helper FSEventStream coalesces the write and pushes it.

**Pass criteria:** File appears in the Supabase mirror. Verify via MCP `garden_inspect` or direct DB read:

```
Path: smoke-push.md should appear with non-null content
```

Alternatively check menubar sync status shows no pending errors.

**Result:** `[ ] PASS  [ ] FAIL — `

---

## Step 4 — Cloud write propagates to local vault (pull path)

**Pre-state:** Sync active. Vault folder set to `~/Desktop/taproot-smoke-vault/`.

**Action:** Using `claude.ai` MCP (`garden_plant`) or direct Supabase insert, write a new file:

```
path: smoke-pull.md
content: "written from cloud"
```

**Observed state:** Within 30 seconds, helper pull cycle applies the write locally.

**Pass criteria:**

```bash
cat ~/Desktop/taproot-smoke-vault/smoke-pull.md
# Expected: "written from cloud"
```

**Result:** `[ ] PASS  [ ] FAIL — `

## Step 5 — Sequential divergent writes (Stage 1 LWW, no crash)

**Pre-state:** `smoke-pull.md` exists locally with content "written from cloud".

**Action (Stage 1 — no simultaneous writes, sequential only):**

1. Locally overwrite the file:
   ```bash
   echo "local edit" > ~/Desktop/taproot-smoke-vault/smoke-pull.md
   ```
2. Wait ~10 s for push to complete.
3. Via MCP / Supabase, overwrite the same path with content "cloud edit v2".
4. Wait ~30 s for pull cycle.

**Observed state:** File on disk reflects last write. No crash. No error in menubar.

**Pass criteria:**

```bash
cat ~/Desktop/taproot-smoke-vault/smoke-pull.md
# Expected: "cloud edit v2" (server last-write wins per Stage 1 semantics)
```

Menubar icon shows no error state.

**Result:** `[ ] PASS  [ ] FAIL — `

## Step 6 — Pause sync; resume with catch-up pull

**Pre-state:** Sync active.

**Action:**

1. Menubar → Pause Sync.
2. While paused, write a new file from cloud (MCP / Supabase):
   ```
   path: smoke-paused.md
   content: "written while paused"
   ```
3. Confirm file does NOT appear locally within 30 s.
4. Menubar → Resume Sync.
5. Wait up to 60 s.

**Pass criteria:**

```bash
cat ~/Desktop/taproot-smoke-vault/smoke-paused.md
# Expected: "written while paused" (catch-up pull applied after resume)
```

**Result:** `[ ] PASS  [ ] FAIL — `

## Step 7 — Sign out cleans up Keychain and stops watcher

**Pre-state:** Signed in, sync active.

**Action:** Menubar → Sign Out.

**Observed state:** Menubar status reflects signed-out state. No sync activity.

**Pass criteria:**

```bash
security find-generic-password -s taproothq.com -w 2>&1
# Expected: "security: SecKeychainSearchCopyNext: The specified item could not be found in the keychain."
# i.e., bearer removed
```

Locally write a file to the vault folder — it should NOT propagate (watcher stopped):

```bash
echo "post-signout" > ~/Desktop/taproot-smoke-vault/smoke-signout.md
# Wait 30s — file should NOT appear in Supabase mirror
```

**Result:** `[ ] PASS  [ ] FAIL — `
